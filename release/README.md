# Скомпільована прошивка

ESP32-WROOM / esp32dev, 4 MB flash; версія2.0.0-lab. Збірку виконано PlatformIO. Ці файли не перевірені на фізичній платі.

Рекомендований спосіб: зібрати й завантажити з firmware/ через `pio run -d firmware -t upload`. PlatformIO сам установлює правильні адреси bootloader, partitions і програми. Не записувати firmware.bin за адресою0x0.

Перед USB зняти JP1 і перевести SW1 у CHARGE, від’єднавши зовнішній зарядний кабель. Після прошивання від’єднати USB, повернути JP1 і RUN. Повні інструкції — docs/firmware.md. SHA256SUMS.txt дає контроль цілісності, а не цифровий підпис.

# Здійсненність PEF

SDP810-500Pa обраний через цифровий вихід, швидкодію та малий діапазон тиску [S1,S2]. Живлення 3.3V входить у допустимі 2.7–5.5V; адреса0x25. Паспортні ±500Pa і 3% від показу з нульовою складовою0.1Pa описують датчик, а не точність всього PEF-метра. Датчик призначений для неконденсувального газу.

Попередня геометрія: D=40mm, d=32mm, β=d/D=0.8. Для оцінки використано Q=Cd·A·sqrt(2Δp/[ρ(1−β⁴)]), Cd=0.62, ρ=1.2kg/m³. Q у м³/с; множення на60000 дає л/хв. Це наближена модель; короткий друкований канал не є стандартною витратомірною діафрагмою з гарантованим Cd.

| Потік, л/хв | Розрахований перепад, Pa |
|---:|---:|
|60|1.425|
|300|35.618|
|600|142.474|
|900|320.566|

Мета стендової перевірки — 60–900 л/хв. Нижня частина діапазону складна через малий перепад. Відносна похибка потоку приблизно половина відносної похибки тиску лише за правильної моделі; геометрія, фільтри, густина, швидкість фронту, витоки й конденсат додають власні похибки. Ніякої медичної точності ці цифри не доводять.

Реальний алгоритм НЕ користується Cd для видачі результатів. Він вимагає таблицю виміряних пар Pa→л/хв, без екстраполяції. Потік поза каліброваним діапазоном робить спробу недійсною. Відсічка |p|≥490Pa дає запас до межі датчика. Цільовий крок збору5ms; розрив>25ms відхиляє спробу. Динаміку піку потрібно перевірити імпульсами еталонного стенда.

MPXV7002 не обрано як дешеву заміну: аналоговий ±2kPa при5V і велика повношкальна похибка несприятливі для перепадів близько1–320Pa [S25]. Потрібні також узгодження до ADC3.3V і окрема метрологія. Дешевий датчик не робить результат медично достовірним.

BTPS/температурно-барометричної компенсації немає. Внутрішню температуру SDP810 драйвер читає, але не використовує як температуру видихуваного газу. Поки що результати віднесено лише до умов конкретного сухого стенда; не порівнювати їх безпосередньо з клінічними PEF-нормами.

Критичні невиконані перевірки блокують використання як медичного приладу. У репозиторії немає вигаданого результату лабораторії, клінічного дослідження чи підпису спеціаліста.

Запуск native: `g++ -std=c++17 -Wall -Wextra -Werror -I firmware/include tests/core_test.cpp firmware/src/measurement.cpp -o core_test && ./core_test`. Web-тест: npm install, npx playwright install chromium, npm test. Для системного Chromium задати CHROMIUM_EXECUTABLE. Потрібні Node22+ і браузерні залежності ОС. CAD: Python cadquery,ezdxf. Після зміни калібрувального/вимірювального коду повторити SW01+SW02, після зміни датчика/каналу — також метрологію.

# Ризики та нормативний план

Не використовувати для лікування гострого нападу. При гострій задишці діяти за призначеним лікарем планом невідкладної допомоги. Прототип не змінює лікування і не робить висновок про напад з одного числа.

| Ризик | Засіб у проєкті | Що ще довести |
|---|---|---|
| Хибний PEF → хибне заспокоєння | Заборона без калібрування, CRC, маркери СТЕНД/DEMO, відсутність медичних зон | Повний діапазон, динаміка, невизначеність, клінічна придатність |
| Завеликий опір | КаналØ40, змінна діафрагма, тільки стенд | Виміряти перепад і відповідність ISO23747; формула не достатня |
| Конденсат/слина | Знімний канал, відводи, краплезбірники, PTFE | Вологі цикли, затримка фільтрів, ресурс, мікробіологія |
| Інфекція/небезпечний матеріал | Заміна контактних деталей, розділення тракту | Біосумісність, валідація очищення; FDM не стерильний |
| Пожежа/коротке замикання | Захищений зарядник, PTC, ізоляція, DPDT | Заряд/нагрів/коротке/відмови із професійною лабораторією |
| Два джерела живлення | JP1 знімається перед USB | Ручний крок помилковий; наступна ревізія має автоматичний power mux |
| Втрата/пошкодження запису | NVS окремими CRC32-слотами, перевірка формату | Power-cut і ресурс flash на реальній платі |
| Неправильна насадка | Ключ рейки, IDрезистор, keyedJ1 | Знос, допуски ADC, відключення під час піку |
| Розголошення даних | BLE вимкнений за замовчуванням; щоденник локальний | Шифрування, автентифікація, контроль доступу — не реалізовані |
| Поломка Nasal зонда | Виносний тримач, лише стенд | Захист від дрібних уламків і вдихання; люди не допускаються |

Це початковий журнал небезпек, не завершений risk-management file. Оцінки ймовірності не вигадано; залишковий ризик для людини не прийнято.

| Документ | Релевантність | Реалізовано / бракує |
|---|---|---|
| ISO23747:2015 [S16] | PEF-метри для функції легень | Одиниці й план калібрування є; нормативна точність/опір/динаміка не підтверджені |
| ISO14971:2019 [S17] | Керування ризиками | Початковий журнал; потрібні повний процес і докази зниження ризику |
| IEC62304:2006+A1:2015 [S18] | Життєвий цикл медичного ПЗ | Модулі, контроль версій і тести; немає повного процесу та класифікації |
| IEC60601-1 ed3.2 [S19] | Електробезпека й основні характеристики | Схема захисту; немає випробувань витоків, одиничних відмов і EMC |
| IEC62366-1:2015+A1:2020 [S20] | Зручність і помилки користувача | UA меню й попередження; потрібні дослідження використання |
| ISO18562-1:2024 [S21] | Біологічна оцінка газового тракту | Архітектурне відокремлення; немає випробувань виділень/частинок |
| ISO10993-1:2025 [S22] | Матеріали контакту з тілом | Позначено контактні деталі; немає біологічної оцінки |

Прочитано відкриті описи/каталоги. Повні нормативні вимоги, національна застосовність і шлях введення в обіг потребують окремої перевірки. Немає сертифікації, твердження про відповідність IEC/ISO або дозволу на продаж як медичного виробу.

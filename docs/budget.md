# Кошторис

Базовий PEF-прототип з AirFlow Basic: **4468.72 грн** за змішаним кошторисом підтверджених цін та інженерних оцінок. З резервом20%: **5362.46 грн**. Насадка NasalTrack потребує додаткового термістора BR11KA104N:16.19EUR за одиницю при мінімальному замовленні5 шт, тобто початкова закупівля80.95EUR плюс доставка й податки [S14]. Курс не вигадано і ця сума не прихована в гривневому підсумку.

SDP810+ESP32 =2010.52 грн. Тому повний прототип до2000 грн з цим сенсором неможливий навіть без дисплея й корпусу. Generic OLED за оціночні120 грн знизить базову суму до3817.72 грн, але потрібні перевірка конкретної плати й переробка кришки.

hardware/BOM.csv містить кількість, номінали, джерела, альтернативи й статус кожної ціни. Оплата власної праці, паяльник, лабораторне джерело, еталон потоку, доставка, клінічні/лабораторні випробування та сертифікація не включені.

Фільтри оцінено як частку спільної лабораторної упаковки. Постачальник SRP15 Q продає500 шт; K2 — інша фасовка. Фактичний чек за цілу упаковку може бути значно більшим. Не замовляти упаковку, не порівнявши локальний продаж окремих фільтрів та інші сумісні гідрофобні бар’єри. Зміна фільтра потребує повторної динамічної калібровки.

Дешевий варіант для Demo Day: ESP32+OLED+кнопки і режим DEMO без датчика. Він демонструє інтерфейс та алгоритм, але НЕ вимірює PEF. Реальні продажі й попит ще не перевірялися: не підміняти ціну комплектуючих рекомендованою роздрібною ціною медичного виробу.

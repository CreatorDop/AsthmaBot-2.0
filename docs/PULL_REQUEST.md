# AsthmaBot 2.0: калібрований PEF-стенд, модулі та історія

Попередній InhaleLab демонстрував координацію вдиху й натискання інгалятора. Ця зміна додає окремий PEF-канал і модульну ESP32-прошивку: без таблиці калібрування реальні л/хв заблоковані, невдалі спроби відхиляються, DEMO явно відокремлений.

Додано7 профілів щоденника, OLEDменю, NVSісторію, BLEGATT і webUI з CSV; електричні схеми, BOM, STEP/STL/DXF, документацію й демонстраційну анімацію. Стару версію збережено в legacy_inhale_lab.

Перевірки: збірка ESP32, nativeC++тести, браузерні сценарії, CAD/DXF і перевірки netlist; точні результати в qa/TEST_REPORT.md. Фізичної перевірки сенсора, BLE, живлення, калібрування й клінічної відповідності немає. Кошторис перевищує2000 грн. AirFlowBasic поки має навчальний екран без кількісного потоку; NasalTrack передає сирий сигнал.

Рев’юеру: перевірити живлення, ручний JP1, метрологічні припущення, обробку відмов і межі безпеки. Не вважати цей PR дозволом на використання з пацієнтами. Злиття потребує підтвердження власника.

# GitHub: стан і передавання

У цьому середовищі не виявлено доступного поточного GitHub-репозиторію AsthmaBot. Не створено сторонній репозиторій і не виконано force-push. Віддалена main не змінювалася. Посилання на PR наразі немає.

Локальна історія містить main з вихідним InhaleLab, archive/asthmabot-before-2 та feature/asthmabot-2. Файл AsthmaBot2_history.bundle дозволяє відновити цю історію. Архів ZIP містить вихідні файли та результати, без .pio, кешів і токенів.

Після отримання URL справжнього репозиторію:

1. Отримати доступ і клонувати його в окрему директорію. Прочитати AGENTS.md, перевірити default branch і поточні зміни.
2. Зберегти саме віддалену попередню версію в archive/asthmabot-before-2 або іншій вільній назві. Не перезаписувати існуючу резервну гілку.
3. Створити feature/asthmabot-2 від актуальної основної гілки. Якщо назва зайнята, спочатку порівняти вміст; не робити force-push.
4. Перенести модернізовані файли з цього пакета, зберігши сторонні файли й історію. Локальна main цього пакета не замінює віддалену main.
5. Запустити тести та secret scan, створити commit і push feature-гілки.
6. Створити PR, використавши docs/PULL_REQUEST.md. Не зливати його без окремого підтвердження користувача.

Для відновлення автономного локального пакета:

```sh
git clone AsthmaBot2_history.bundle AsthmaBot2
git -C AsthmaBot2 switch feature/asthmabot-2
```

Вихідні генератори документів і моделей містяться в tools/. Вони мають залежності, наведені у requirements-tools.txt. Код презентації призначений для нативного редактора презентацій; редагований PPTX додається незалежно від нього.

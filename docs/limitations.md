# Що ще не працює або не підтверджено

- Фізичного приладу немає: прошивку скомпільовано, але на ESP32 не завантажено й з реальним SDP810 не випробувано.
- Справжнього калібрування немає. Без нього л/хв заблоковані. Немає підтвердженої точності/діапазону, BTPS і відповідності ISO23747.
- AirFlow Basic має геометрію та екран навчального режиму; кількісний контроль потоку й вправи зі зворотним зв’язком не реалізовані.
- NasalTrack передає сирі мВ; автоматичний підрахунок частоти, детекція апное/нападів не реалізовані. Тримач крихкого датчика потребує доопрацювання.
- BLE-код та Web Bluetooth написані; зв’язок з фізичним телефоном і ESP32 не перевірено. Автентифікації немає.
- Історія96 записів, OLED показує лише останній; RTC немає, час встановлюється смартфоном/USB після запуску.
- Відсоток заряду приблизний; автономність і зарядна терміка не виміряні. USB-оновлення є, OTA немає.
- CAD валідний як геометрія, але не є випущеною у виробництво конструкторською документацією. Посадки, герметичність, гвинти, тримачі й реальні плати треба приміряти.
- Мундштук, FDM-матеріали й очищення не валідовані. Людські дихальні проби не входять у поточну демонстрацію.
- Кошторис перевищує2000 грн. Мінімальні упаковки й доставка можуть збільшити фактичну закупівлю.
- Поточний віддалений GitHub-репозиторій недоступний; PR не створено. Локальна feature-гілка й резерв старої версії є.

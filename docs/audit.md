# Аудит попередньої роботи

Попередній локальний пакет InhaleLab містив концепцію тренажера узгодження вдиху з натисканням інгалятора, CAD, електричний ескіз, кошторис, браузерну демонстрацію та презентацію. Це не був перевірений PEF-метр. Знайдені файли збережено в legacy_inhale_lab/ без підміни їхнього призначення.

| Частина | Рішення для AsthmaBot 2.0 |
|---|---|
| ESP32, цифровий датчик тиску | Зберегти напрям, заново перевірити живлення, контакти й драйвер |
| Канал вдиху з діафрагмою Ø12 | Не переносити на піковий видих; новий канал Ø40 / діафрагма Ø32 |
| Алгоритм натискання pMDI | Замінити збором PEF, перевіркою якості, історією та калібруванням |
| HTML-демо | Зберегти як архів; новий UI з BLE, CSV і розділенням DEMO/СТЕНД |
| Висновки про навчальну техніку | Не переносити на діагностику астми |
| Кошторис/креслення | Перерахувати під конкретні плати та акумулятор |
| GitHub | Доступного поточного репозиторію не знайдено. Його історію не вважати перевіреною |

Локально main і archive/asthmabot-before-2 зберігають вихідний пакет. Робоча гілка feature/asthmabot-2. Це резервна локальна історія, а не доказ резервування невідомої віддаленої main. Для PR потрібні URL і доступ до справжнього репозиторію; після отримання треба спочатку порівняти його з цим пакетом, а не перезаписувати.

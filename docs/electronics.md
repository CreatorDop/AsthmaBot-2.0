# Електроніка та схема

Файли hardware/AsthmaBot2_logic.kicad_sch і AsthmaBot2_power.kicad_sch відкриваються KiCad9; PDF — для перегляду. Це принципова схема з’єднань готових модулів із повною контактною таблицею connections.csv. Внутрішні схеми купованих плат не дублюються. Однакові імена мереж на двох окремих аркушах означають з’єднання при монтажі; це не багатолистовий KiCad-проєкт із наскрізним ERC. Перед PCB потрібні нормальні бібліотечні символи, footprints і повний ERC/DRC.

SDP810 контакт1=SCL,2=VDD,3=GND,4=SDA — перевірити орієнтацію за нижнім видом datasheet. OLED контакти звіряти за написами GND/VCC/SCL/SDA: порядки на дешевих платах відрізняються. ESP32 GPIO не толерантні до5V. Обидва цифрові сенсори працюють від3V3, рівневі перетворювачі не потрібні.

RPROG=4.7k замість штатного резистора TP4056 задає приблизно0.25A; це проєктна установка, фактичний струм перевіряється амперметром. У4 обов’язково має захист DW01A+FS8205A. B− — тільки мінус елемента; загальний GND — OUT−, інакше захист обходиться. Не паяти безпосередньо до банки: потрібні заводські приварені виводи й ізоляція.

SW1 має два механічно зв’язані полюси: CHARGE з’єднує USB5V із IN+ зарядника й відключає boost; RUN відключає зарядний вхід і подає PACK+ на boost. Вбудований USB роз’єм U4 закрити, щоб не обійти SW1. Boost налаштувати на5.00V без ESP32, перевірити під навантаженням0.5A і на мінімальній напрузі елемента. JP1 зняти перед USB-прошиванням. Це ручне блокування, помилка користувача все ще можлива.

Оцінка заряду за напругою приблизна: лінійне відображення3.3–4.2V не є кулонним лічильником. При<3.35V новий стендовий PEF блокується. Калібрувати множник ADC мультиметром. Час автономності не виміряно; розрахунок без реального профілю струму не подавати як специфікацію.

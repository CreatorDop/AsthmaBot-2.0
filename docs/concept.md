# Концепція та архітектура

AsthmaBot 2.0 — відкритий навчальний стенд для дослідження пікового потоку видиху й інтерфейсу персональної історії. Потенційна користь — зручніше записувати спостереження та обговорювати їх із фахівцем. Прототип не діагностує астму, не прогнозує напад і не призначає лікування.

Потік через PeakFlow створює різницю тиску на діафрагмі. Два відводи через краплезбірники й гідрофобні фільтри ведуть до SDP810. ESP32 читає тиск по I2C, перевіряє CRC і шкалу, віднімає нуль, використовує виміряну калібрувальну таблицю та зберігає максимум. Окремий I2C обслуговує OLED. Історія й налаштування — NVS; смартфон — BLE GATT. Щоденник зберігається локально у браузері.

Живлення: один Li-ion → захищений TP4056 → перемикач CHARGE/RUN → boost5V → ESP32; його 3V3 живить сенсор/OLED. Заряджання і роботу навантаження розведено механічним DPDT. Перед USB-прошиванням знімається JP1, щоб не подавати два джерела на DevKit.

| Модуль | Реальна функція цієї версії | Межа |
|---|---|---|
| AirFlow Basic | Змінний мундштук і відкритий канал Ø40; ідентифікація 1k | Екран навчального режиму, без кількісного потоку та керованого опору |
| PeakFlow | Канал, діафрагма, відводи, ID4.7k, драйвер і алгоритм PEF | Л/хв заблоковані без калібрування; фізична точність не встановлена |
| NasalTrack | ID10k, NTC100k, імпульсне збудження, сирі мВ та графік5 Гц | Ритм можна досліджувати за сигналом; частота/апное автоматично не визначаються |

PEF — максимальна миттєва швидкість потоку в л/хв, не об’єм легенів. FEV1 та FVC тут не реалізовані. Демонстраційна крива повністю задана математично й завжди позначена DEMO. Це дозволяє показати алгоритм без дихальних проб.

Два етапи розвитку: спочатку сухий повітряний стенд і метрологія; потім перегляд конструкції, матеріалів, гігієни й випробування за участю фахівців. Продаж як медичного виробу на поточній стадії не обґрунтований. Патентна новизна не підтверджена; пошук аналогів не дорівнює перевірці патентної чистоти.
